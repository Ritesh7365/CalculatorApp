# CalculatorApp
<img width="672" height="1280" alt="image" src="https://github.com/user-attachments/assets/661a6370-ee2e-4727-9bdd-870c3fa8cdd6" />

Simple calculator app for iPhone made with SwiftUI. Looks similar to the default iOS calculator.

Made this while learning iOS development.

## Features
- add, subtract, multiply, divide
- decimal, % and +/-
- AC to clear
- shows Error on divide by 0

## Run
Open `CalculatorApp.xcodeproj` in Xcode, select an iPhone simulator and hit Cmd+R.

## Tech
Swift, SwiftUI, Xcode 27
